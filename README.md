# ReferenceData_2026_BreedingScience

This repository contains the data and R/Stan code used for the analyses in the manuscript: “Quantifying cultivar-specific heat tolerance for rice grain appearance quality by re-analysis of systematic review data”.

## Repository structure

### Data

The `Data` directory contains the input data used in the analyses.

- `CG_database.xlsx`: Database of rice grain appearance quality compiled from published studies and databases. This dataset was originally published by Wakatsuki et al. (2024) and is available from [Mendeley Data](https://data.mendeley.com/datasets/xwv7bpp5rn/2).
- `meshdat.rds`: Daily weather data corresponding to the records in `CG_database.xlsx`. Weather data for the grain-filling period were extracted from the Historical Gridded Meteorological Dataset in Japan based on the latitude, longitude, and heading date of each record. The original gridded meteorological dataset is available from [Science Data Bank](https://www.scidb.cn/en/detail?dataSetId=0a094405c6d24f8e88f21f438145c2c2) and is described by Ishigooka et al. (2026).

### Script

The `Script` directory contains the R and Stan scripts used for data preprocessing and model fitting.

- `1_DataPreparation.R`: Imports and cleans `CG_database.xlsx` and organizes the data and metadata. The processed data are saved in the `Result` directory.
- `2_MainModels.stan`: Defines the Bayesian models used to estimate cultivar-specific responses of chalky grain proportion to temperature, solar radiation, and relative humidity.
- `2-1_ParameterEstimation_MainModels.R`: Fits the main candidate models using `rstan`. Posterior summaries, convergence diagnostics, RMSE, WAIC, and leave-one-out cross-validation results are saved.
- `2-2_ParameterEstimation_Wakatsuki2024.R`: Fits the model corresponding to the structure proposed by Wakatsuki et al. (2024) and saves the parameter estimates and model evaluation results.

### Result

The `Result` directory contains the processed datasets, parameter summaries, model evaluation results, and diagnostic figures generated by the scripts.

Fitted Stan objects saved as `.rds` files are not included in this repository because of their large file sizes. These files can be regenerated by running the corresponding parameter-estimation scripts.

## Analysis workflow

Run the scripts from the root directory of the repository in the following order:

1.  `Script/1_DataPreparation.R`
2.  `Script/2-1_ParameterEstimation_MainModels.R`
3.  `Script/2-2_ParameterEstimation_Wakatsuki2024.R`

The Stan model in `Script/2_MainModels.stan` is compiled and called from the parameter-estimation scripts.

## Software requirements

The analyses require R, Stan, a working C++ toolchain, and the following R packages:

- `openxlsx`
- `rstan`
- `loo`
- `gridExtra`
- `ggplot2`
- `timechecker`
